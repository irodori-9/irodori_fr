# たなぼたミッション機能 要件定義書

## 概要
ホームページのマンスリーサマリーの下に「たなぼたミッション！」セクションを追加し、ユーザーがミッションを完了することでポイントを獲得できる機能を実装する。

## 機能要件

### 1. 基本構成
- **配置場所**: ホームページ（`/src/app/home/page.tsx`）のマンスリーサマリーセクションの直下
- **セクションタイトル**: 「たなぼたミッション！」
- **データソース**: `public/mission.csv`ファイルから動的に読み込み

### 2. ミッションカードのレイアウト
各ミッションは以下の要素を含むカード形式で表示：

#### 2.1 カード構成要素
- **ミッションタイトル**: ミッションの説明文（例：「INIカムバック「The Origin」の感想をストーリーに投稿しよう！」）
- **サブテキスト**: 補足説明（例：「サンリオキャラクターズのことをインスタに写真を添えて投稿しよう！」）
- **報酬金額**: ¥xxx形式で表示
- **アクションボタン**: ミッション内容に応じたラベル（例：「投稿する！」「見た！」）
- **ミッション画像**: 関連する画像（オプション）

#### 2.2 視覚的デザイン
- 白背景のカード（`bg-white`）
- 角丸デザイン（`rounded-xl`）
- シャドウ効果（`shadow-sm`）
- 適切なパディング（`p-4`）
- カード間のマージン（`space-y-4`）

### 3. データ管理

#### 3.1 CSVファイル構造（mission.csv）
```csv
id,title,subtitle,reward,button_text,image_path,status,category
1,"INIカムバック「The Origin」の感想をストーリーに投稿しよう！","サンリオキャラクターズのことをインスタに写真を添えて投稿しよう！",300,"投稿する！","/images/missions/ini-origin.jpg","active","social"
2,"aespaの広告を見に行こう","新宿駅にあるaespaの広告を見に行こう！",300,"見た！","/images/missions/aespa-ad.jpg","active","location"
```

#### 3.2 データ項目詳細
- `id`: ミッション識別子（数値）
- `title`: ミッションタイトル（文字列）
- `subtitle`: サブテキスト（文字列、オプション）
- `reward`: 報酬金額（数値）
- `button_text`: アクションボタンのテキスト（文字列）
- `image_path`: ミッション画像のパス（文字列、オプション）
- `status`: ミッションステータス（"active", "inactive", "completed"）
- `category`: ミッションカテゴリ（"social", "location", "challenge"等）

### 4. 機能的要件

#### 4.1 データ取得
- ページロード時にCSVファイルを読み込み
- `status="active"`のミッションのみ表示
- エラーハンドリング（CSVファイルが存在しない場合等）

#### 4.2 ユーザーインタラクション
- アクションボタンクリック時のハンドリング
- ミッション完了状態の管理（ローカルストレージまたはAPI連携）
- 完了済みミッションの表示状態変更

#### 4.3 レスポンシブデザイン
- モバイル対応（カードの縦配置）
- タブレット・デスクトップ対応（適切な幅調整）

### 5. 実装要件

#### 5.1 コンポーネント構造
```
HomePage
├── MonthlySummary (既存)
└── TanabotaMissionSection (新規)
    ├── SectionTitle
    └── MissionCardList
        └── MissionCard (複数)
            ├── MissionImage
            ├── MissionContent

```

#### 5.2 使用技術
- **フレームワーク**: Next.js (React)
- **スタイリング**: Tailwind CSS
- **アニメーション**: Framer Motion（既存パターンに合わせる）
- **画像処理**: Next.js Image コンポーネント
- **データ処理**: CSV parsing library (papa-parse等)

#### 5.3 ファイル構成
- `/src/app/home/page.tsx` - メインページに統合
- `/src/components/TanabotaMissionSection.tsx` - ミッションセクション（新規作成）
- `/src/components/MissionCard.tsx` - ミッションカード（新規作成）
- `/public/mission.csv` - ミッションデータ（新規作成）
- `/public/images/missions/` - ミッション画像フォルダ（新規作成）

### 6. 画像要件

#### 6.1 ミッション画像
- サイズ: 横幅150px程度、縦横比2:1または1:1
- フォーマット: JPG、PNG
- 格納場所: `/public/images/missions/`
- ファイル名: わかりやすい命名規則（例：`ini-origin.jpg`, `aespa-ad.jpg`）

#### 6.2 画像最適化
- Next.js Imageコンポーネントによる自動最適化
- lazy loading対応
- alt属性の適切な設定

### 7. 状態管理

#### 7.1 ミッション完了状態
- ローカルストレージを使用して完了状態を保存
- キー: `completed_missions`
- 値: 完了済みミッションIDの配列 `[1, 3, 5]`

#### 7.2 状態の永続化
```javascript
// 完了状態の保存
const markMissionComplete = (missionId) => {
  const completed = JSON.parse(localStorage.getItem('completed_missions') || '[]');
  if (!completed.includes(missionId)) {
    completed.push(missionId);
    localStorage.setItem('completed_missions', JSON.stringify(completed));
  }
};
```

### 8. パフォーマンス要件
- CSVファイルの読み込み時間: 1秒以内
- 画像の読み込み: lazy loading で必要時のみ
- アニメーション: 60fps維持

### 9. セキュリティ要件
- CSVファイルの内容は公開情報のみ
- XSS対策: テキスト内容のサニタイズ
- ユーザー入力は最小限（ボタンクリックのみ）

3. **フェーズ3**: 画像・スタイリング
   - ミッション画像の追加
   - デザインの最終調整
   - レスポンシブ対応

4. **フェーズ4**: テスト・最適化

### 12. 非機能要件

#### 12.1 可用性
- 99.9%の稼働率
- CSVファイル読み込みエラー時のグレースフルデグラデーション

#### 12.2 保守性
- コンポーネントの再利用性
- 明確なコメントとドキュメンテーション
- ESLint/Prettierによるコード品質管理

#### 12.3 ユーザビリティ
- 直感的なUI/UX
- アクセシビリティ対応（aria-label等）
- タッチデバイスでの操作性
