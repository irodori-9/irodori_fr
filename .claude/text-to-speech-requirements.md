# チャットボット合成音声読み上げ機能 要件定義書

**プロジェクト**: IRODORI - Tanabota Banking Application  
**機能名**: チャットボット合成音声読み上げ機能（TTS: Text-to-Speech）  
**作成日**: 2025年8月15日  
**バージョン**: 1.0.0

---

## 📋 概要

### プロジェクト背景
既存のチャットボット機能（TANABUTAちゃん）に、生成AIで生成したメッセージを合成音声で読み上げる機能を追加し、よりアクセシブルで親しみやすいユーザー体験を提供する。

### 機能概要
TANABUTAちゃんの返答メッセージを自動的に合成音声で読み上げ、視覚的な情報に加えて聴覚的な情報提供により、ユーザビリティの向上を図る。

## 🎯 要件定義

### 1. 基本要件

#### 1.1 音声合成タイミング要件
- **要件ID**: TTS-001
- **要件名**: 音声合成準備完了時の表示・再生
- **内容**: 合成音声まで準備が整ったタイミングでUI上のメッセージを表示し音声を再生する
- **詳細**: 
  - TANABUTAちゃんの返答テキストが確定した時点で音声合成APIを呼び出し
  - 音声データの準備が完了してからメッセージをチャット履歴に表示
  - 表示と同時に音声の自動再生を開始
- **優先度**: 高

#### 1.2 音声API要件
- **要件ID**: TTS-002
- **要件名**: /speech API の使用
- **内容**: 合成音声は `/speech` のAPIを使用する
- **詳細**:
  - エンドポイント: `/api/speech`
  - 入力: テキストデータ（TANABUTAちゃんの返答）
  - 出力: WAVファイル形式の音声データ
  - HTTP メソッド: POST
- **優先度**: 高

#### 1.3 音声再生要件
- **要件ID**: TTS-003
- **要件名**: ブラウザでの音声再生
- **内容**: APIから返却されたWAVファイルをブラウザで直接再生する
- **詳細**:
  - HTML5 Audio API を使用
  - 音声ファイルのBlobデータを直接再生
  - クロスブラウザ対応（Chrome, Firefox, Safari, Edge）
- **優先度**: 高

### 2. 機能要件

#### 2.1 ユーザーインターフェース要件
- **要件ID**: TTS-004
- **要件名**: 音声再生状態表示
- **内容**: 音声再生中であることをUIで表示する
- **詳細**:
  - 音声再生中のビジュアルインジケーター表示
  - TANABUTAちゃんのアニメーション（口パク、音波等）
  - 再生進行状況の表示
- **優先度**: 中

#### 2.2 音声制御要件
- **要件ID**: TTS-005
- **要件名**: 音声再生制御機能
- **内容**: ユーザーが音声再生を制御できる機能を提供する
- **詳細**:
  - 音声の一時停止・再開機能
  - 音声の停止機能
  - 音量調整機能（オプション）
  - 再生速度調整機能（オプション）
- **優先度**: 中

#### 2.3 マルチメッセージ対応要件
- **要件ID**: TTS-006
- **要件名**: 複数メッセージの音声制御
- **内容**: 複数のTANABUTAちゃんメッセージがある場合の音声制御
- **詳細**:
  - 新しい音声再生時は既存の音声を停止
  - 音声再生キューの管理（オプション）
  - 同時再生の防止
- **優先度**: 中

### 3. 技術要件

#### 3.1 API仕様要件
- **要件ID**: TTS-007
- **要件名**: /speech API 仕様
- **内容**: 音声合成APIの詳細仕様定義
- **詳細**:
  ```
  エンドポイント: POST /api/speech
  Content-Type: application/json
  
  リクエストボディ: 
  {
    "text": "読み上げるテキスト (string, required)",
    "speaker": 3 (number, 話者ID),
    "speedScale": 1 (number, 話速調整),
    "pitchScale": 0 (number, 音高調整),
    "intonationScale": 0 (number, 抑揚調整),
    "volumeScale": 0 (number, 音量調整),
    "prePhonemeLength": 0 (number, 音素前の無音時間),
    "postPhonemeLength": 0 (number, 音素後の無音時間)
  }
  
  レスポンス: WAVファイル (audio/wav)
  Content-Type: audio/wav
  ```
- **優先度**: 高

#### 3.2 エラーハンドリング要件
- **要件ID**: TTS-008
- **要件名**: 音声合成エラーハンドリング
- **内容**: 音声合成に関する各種エラーへの対応
- **詳細**:
  - API通信エラー時の処理（タイムアウト、ネットワークエラー等）
  - 音声ファイル再生エラー時の処理
  - ブラウザ音声機能非対応時の処理
  - エラー時でもテキストメッセージは正常表示
- **優先度**: 高

#### 3.3 パフォーマンス要件
- **要件ID**: TTS-009
- **要件名**: 音声合成・再生パフォーマンス
- **内容**: 快適なユーザー体験のためのパフォーマンス要件
- **詳細**:
  - 音声合成API応答時間: 5秒以内
  - 音声ファイルサイズ: 1MB以下/30秒以内の音声
  - メモリ使用量の最適化
  - 音声キャッシュ機能（オプション）
- **優先度**: 中

## 🔄 機能フロー

### 1. メインフロー
```
1. ユーザーが音声入力
2. 音声 → テキスト変換（既存機能）
3. TANABUTAちゃんがAI応答生成（既存機能）
4. AI応答テキストを/speech APIに送信 ← 新機能
5. WAVファイル生成・取得 ← 新機能
6. 音声準備完了後、メッセージ表示 ← 修正
7. 音声の自動再生開始 ← 新機能
8. 再生状態をUIで表示 ← 新機能
```

### 2. エラーフロー
```
音声合成エラー発生時:
1. エラーをキャッチ
2. メッセージはテキストのみで表示
3. エラーログ記録
4. ユーザーには「音声の準備ができませんでした」等の表示
```

## 🎨 UI/UX設計要件

### 1. 音声再生インジケーター
- TANABUTAちゃんの口元に音波アニメーション
- 再生中は吹き出しに音符アイコン表示
- 音声読み込み中はローディングアニメーション

### 2. 音声制御UI
- 吹き出し内に小さな再生/停止ボタン
- 音量アイコン（クリックで音声のON/OFF切り替え）
- 音声無効時は吹き出しに「🔇」アイコン表示

### 3. アニメーション
- 音声再生開始時: フェードイン + 音波エフェクト
- 音声再生中: 口パクアニメーション or 音波の点滅
- 音声再生完了時: フェードアウト
